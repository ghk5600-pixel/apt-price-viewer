# 건축HUB 공급면적 검증 결과

검증일: 2026-07-29

## 결론

건축HUB `건축물대장 전유공용면적 조회(getBrExposPubuseAreaInfo)` 결과만으로
아파트 공급면적을 산출할 수 있다.

검증한 서울 아파트 12개 단지의 대표 면적형 모두 네이버페이 부동산 공급면적과
`0.01㎡ 이하` 오차로 일치했다. 차이는 소수점 표시 자릿수에 따른 반올림 수준이다.

## 산식

```text
공급면적 = 전용면적 + 주거공용면적
주거공용면적 = 구조·동선 공용면적 + 세대 배분 대피소 면적
공급평형 = 공급면적 ÷ 3.305785
공급평당가 = 거래금액 ÷ 공급평형
```

주거공용으로 포함한 용도:

- 벽체
- 계단, 계단실
- 복도, 홀, 현관
- 승강기, 엘리베이터
- 코아/코어, 로비, 라운지
- 세대별로 배분된 대피소

제외한 기타 공용:

- 지하주차장
- 기계실, 전기실, 발전기실, 펌프실
- 관리사무소, 경비실
- 주민공동시설, 운동시설, 수영장, 사우나
- 어린이집, 경로당, 도서관, 회의실 등

한 행에 주거 동선과 커뮤니티 용도가 섞여 있으면 그 행은 기타 공용으로 처리했다.

## 주소 보정

공동주택관리 API 주소에는 재건축 전 지번이 남아 있는 사례가 있었다. 건축HUB 조회에는
현재 건축물대장 지번을 사용해야 한다.

| 단지 | 관리 API 지번 | 건축HUB 지번 |
|---|---:|---:|
| 래미안대치팰리스 | 대치동 633 | 대치동 1027 |
| 헬리오시티 | 가락동 479 | 가락동 913 |
| 디에이치자이개포 | 일원동 611-1 | 일원동 743 |
| 래미안원베일리 | 반포동 1-1 | 반포동 1 |

래미안원베일리의 `반포동 1-1`은 원베일리 스퀘어 건축물대장이고, 아파트 전유부는
`반포동 1`에서 조회된다.

## 구현 시 주의점

건축HUB의 각 세대는 `mgmBldrgstPk`로 묶고 전유 행 1개와 공용 행 여러 개를 합산해야 한다.
단지 단위 응답은 수만 건이 될 수 있으므로 브라우저에서 매번 전량 조회하면 안 된다.
백엔드에서 한 번 수집하고 장기 캐시한 뒤 전용면적별 공급면적 목록만 프런트엔드에 제공하는
구조가 적절하다.

같은 전용면적에도 A/B/C 타입별 공급면적이 다를 수 있다. 실거래 데이터의 동 정보로 먼저
좁히고, 그래도 여러 공급면적이 남으면 임의로 하나를 확정하지 않는다.

- 하나로 확정: `공급 112.85㎡`, 공급평당가 표시
- 여러 후보: `공급 111.72~112.85㎡`, 공급평당가 범위 표시
- 대표값 사용 시: `추정` 배지와 산정 근거 표시
